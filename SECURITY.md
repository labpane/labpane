# Security policy

## Supported versions

Security fixes go into the latest release of `@labpane/os` and `@labpane/ui`.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through GitHub instead: [report a vulnerability](https://github.com/labpane/labpane/security/advisories/new).

Include the affected package and version, what an attacker could do with it, and the steps or code that reproduce it. We'll reply in the advisory and credit you in the release notes unless you'd rather not be named.
